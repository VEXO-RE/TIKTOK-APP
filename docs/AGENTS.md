# Reglas de Documentation

Aplican con AGENTS.md de raíz; instrucciones actuales del usuario prevalecen.

- Propósito: Estados/fuentes y diseño.
- Reglas obligatorias locales: Distinguir propuesta/implementación/evidencia; no conservar contradicciones; enlazar índices; no copiar grandes manuales externos.
- Gate: Rutas/JSON/enlaces/skill válidos, fuente de afirmaciones.
- Consultar docs/development/README.md y DEVELOPMENT.md de esta sección antes de implementar.
- Documento/carpeta no acredita backend operativo; preservar cambios actuales y scopes de tarea.
