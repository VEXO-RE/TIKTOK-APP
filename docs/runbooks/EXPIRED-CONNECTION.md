# Conexión expirada o proceso reiniciado

Tokens Sandbox solo memoria; restart pierde conexión. No persistirlos en JSON para recuperarla.
Mostrar no conectado y repetir autorización TikTok. No manipular scope/tokens desde navegador.
Cancelar o pausar jobs de la cuenta hasta conexión/autorización válidas; cualquier cambio de cuenta exige nueva aprobación.
Revocación no es error temporal para reintentar sin fin.
Producción necesita diseño separado de cifrado/refresh/tenant y revisión autorizada.
