# Reglas de Review UI

Aplican con AGENTS.md de raíz; instrucciones actuales del usuario prevalecen.

- Propósito: Preview/approval/status de la cuenta destino.
- Reglas obligatorias locales: No JSON técnico para UX final; botón no hace promesa falsa; frontend nunca sustituye approval/idem del servidor.
- Gate: Preview real, aprobación visible y guard; evidencia diferenciada.
- Consultar docs/development/DISENO.md y DEVELOPMENT.md de esta sección antes de implementar.
- Documento/carpeta no acredita backend operativo; preservar cambios actuales y scopes de tarea.
