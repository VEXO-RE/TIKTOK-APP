# Reglas de Config

Aplican con AGENTS.md de raíz; instrucciones actuales del usuario prevalecen.

- Propósito: Defaults y referencias seguras.
- Reglas obligatorias locales: Cambios solo en fase autorizada; secrets no versionados; defaults cierran mutaciones; flags no equivalen a permiso.
- Gate: Schema config/env tests; sin valores reales en docs.
- Consultar docs/development/OPERACION.md y DEVELOPMENT.md de esta sección antes de implementar.
- Documento/carpeta no acredita backend operativo; preservar cambios actuales y scopes de tarea.
