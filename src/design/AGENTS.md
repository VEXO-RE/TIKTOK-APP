# Reglas de Design

Aplican con AGENTS.md de raíz; instrucciones actuales del usuario prevalecen.

- Propósito: Sistema visual y QA de interfaz.
- Reglas obligatorias locales: Activos aprobados, tokens semánticos, accessibility, estados; evitar claims falsos y nombres técnicos en UX.
- Gate: Capturas/QA móvil real, keyboard/focus y cuenta visible.
- Consultar docs/development/DISENO.md y DEVELOPMENT.md de esta sección antes de implementar.
- Documento/carpeta no acredita backend operativo; preservar cambios actuales y scopes de tarea.
