# Reglas de Content

Aplican con AGENTS.md de raíz; instrucciones actuales del usuario prevalecen.

- Propósito: Briefs, revisiones, calendario y aprobación.
- Reglas obligatorias locales: Snapshot inmutable, sources/fecha/expiry, UTC/zona y approval/hash; conservar schema inicial hasta migración versionada.
- Gate: Cambio de cuenta/CTA/asset invalida; transición y calendario probados.
- Consultar docs/development/CONTRATOS.md y DEVELOPMENT.md de esta sección antes de implementar.
- Documento/carpeta no acredita backend operativo; preservar cambios actuales y scopes de tarea.
