# TikTok for Developers

This directory will contain ONLY functionality verified against
official TikTok for Developers documentation.

Initial target products:

- Login Kit
- Content Posting API

Initial organic publishing strategy:

1. authenticate authorized ShopinistaMeta accounts;
2. prepare editorial content;
3. upload approved media;
4. allow required user completion when TikTok requires it;
5. enable Direct Post only after approval and audit requirements
   have been satisfied.

Do not add endpoints, scopes or request parameters from memory.

Official sources must be registered in:

docs/OFFICIAL-SOURCES.md
